# Catherine Lazare - Marketing Strategy Portfolio

A recruiter-facing Next.js portfolio for marketing strategy, CRM, revenue operations, and business analytics roles. The four included projects are explicitly labeled as independent strategic/portfolio case studies and do not claim client, employer, or measured financial results.

## Run locally

Requires Node.js 18.17 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Quality checks:

```bash
npm run lint
npm run build
npm start
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, select **Add New > Project** and import that repository.
3. Choose the **Next.js** framework preset. Vercel detects `npm run build` automatically.
4. No environment variables are required.
5. Select **Deploy**. Future commits to the connected production branch automatically create new production deployments; pull requests receive preview deployments.

There are no absolute paths, localhost production dependencies, or runtime APIs. Before launch, add a recruiter-safe public résumé file and confirmed public contact details.

## Source-material note

The workspace used for this build did not contain the original GitHub marketing project files. The case studies therefore use non-quantified strategic frameworks only. Add verified analysis, charts, recommendations, and conclusions from the source repository when it becomes available.
